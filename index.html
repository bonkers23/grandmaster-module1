Structure of HTML

HTML (HyperText Markup Language) is used to create the structure of a web page. Every HTML document follows a fixed structure.

Basic Parts of HTML

  • <!DOCTYPE html> Defines the document type (HTML5)
  • <html> Root element of the HTML page
  • <head>Contains meta information and title
  • <title>Displays the page title on the browser tab
  • <body> Contains all visible content of the webpage

Conclusion

Understanding the structure of HTML is the first step towards learning web development. It helps students build well-organized and readable web pages.
